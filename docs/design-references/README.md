# PopBox 路演界面视觉基准

主参考图：`popbox-roadshow-visual-concept-v1.png`

## 页面锚点

- 生命仓：潮玩包装盒结构，大面积荧光绿，照片为主视觉，参数区紧凑，橙色主按钮。
- 今日同游：独立杂志排版，大标题、期号、时间线、四色场景条、角色对话色块、拍立得。
- 小纸条：软木板、真实纸张、胶带或图钉，优先保留物理留言板语义。
- 出行照片墙：牛皮纸相册墙、拍立得、胶带，工具栏弱化为贴纸式控制条。

## 每轮视觉修改流程

1. 修改前查看主参考图。
2. 修改后用 Playwright 截取对应页面。
3. 对照检查版式主次、色块面积、字体层级、物理材质、留白和交互可读性。
4. 只修正明确差距，不为增加装饰而增加装饰。
